Privacy by design

Your research notes stay in this browser unless you export them. Model API calls send your prompt and selected research excerpts to the provider you configure. API keys are kept in session memory only and cleared when the tab session ends.

For Ollama, the server must allow browser CORS and be reachable from your iPhone. A local model on another device is not literally running on the iPhone. Never expose a secret key in a public GitHub repository.
